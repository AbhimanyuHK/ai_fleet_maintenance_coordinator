# Fault Code Reference

Document ID: DOC002
Source: OEM Fault Code Reference
Version: 1.0
Status: APPROVED

## BRK-001
Brake system fault. Inspect the brake system and associated components before returning equipment to service.

## ENG-014
Engine sensor fault. Perform diagnostic checks for the affected sensor circuit, replace failed components according to the approved procedure, and clear the fault only after verification.

## GEN-002
General electrical fault. Diagnose the affected circuit and document the corrective action before closing the work order.
