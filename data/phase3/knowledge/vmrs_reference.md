# VMRS Coding Reference
- Document ID: VMRS-001
- Source Type: Company Reference
- Authority: HIGH
- Version: 1.0
- Effective Date: 2026-01-01

VMRS coding should accurately represent the component, repair action, and maintenance work performed. Completed work orders must match final invoices and include applicable VMRS breakdowns and documentation. Incorrect or missing coding should be routed for review before work-order closure.
